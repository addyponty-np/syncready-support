Common questions

Will scanning change my files?

No. Scanning reads names, paths, and filesystem metadata. A rename happens only after you select items, review the exact proposed changes, and choose Rename. SyncReady does not read file contents or upload them.

What does a clean scan mean?

No issues were found among the checks and items the scan completed. It is not a guarantee that a cloud service or another application will accept everything. If you stop a scan or some folders cannot be inspected, its results are incomplete. Review any skipped-item messages.

Why are cloud files or linked folders skipped?

Links, junctions, and some cloud-managed items use special filesystem attributes. SyncReady does not follow these locations or repair them automatically. This prevents a scan or rename from affecting a location you did not select. A scan may therefore leave parts of a managed cloud folder uninspected, even if they appear in File Explorer.

Why is a suggested repair unavailable?

Some findings need a decision that a rename cannot safely make: for example, a long parent path, a temporary file, an ambiguous collision, or an unavailable cloud item. Read the explanation for that finding. Resolve it in the relevant app or File Explorer, then scan again. SyncReady never deletes files, overwrites another item, or merges folders as a repair.

How do I undo a rename?

Open Repair history, select the recorded repair, and choose Undo. SyncReady checks the current file identity, metadata, and original destination before restoring names. If files have moved, changed, or another item now occupies a destination, Undo may stop. Keep the recovery folder and its authentication key; history and Undo for completed repairs are available without Pro.

A repair stopped or the app closed. What now?

Reopen SyncReady and review Repair history before making more changes. The app saves a recovery record before renaming and does not automatically modify your files when reopened. Use the recorded status and Undo where available. If a conflict is reported, keep the recovery files and describe the error code to support without uploading the recovery records.

What is included in Free and Pro?

Free includes unlimited Windows and Windows + OneDrive scans, five individual evaluation renames, and recovery history and Undo for performed repairs. Pro is an optional one-time Microsoft Store purchase for bulk repair, additional compatibility profiles, migration preview, custom thresholds and excluded checks, CSV reports, and scanning several folders in one session. Pro is not a subscription.

How many names can I repair at once?

You can review up to 1,000 changes per folder in a transaction with Pro. This keeps the durable recovery record manageable. For more changes, rescan and review another batch. Scanning itself is not limited to 1,000 items.

Does migration preview move my files?

No. It calculates possible paths under the destination you enter and checks those names and paths. It does not copy, move, sync, or upload files. A separate cloud path-length check requires the actual decoded OneDrive or SharePoint destination folder path; a sharing link is not the same thing.

I bought Pro, but it does not appear active.

Check that Microsoft Store is signed in to the account used for the purchase, connect to the internet, and choose Restore purchase in SyncReady. Availability and the displayed price come from Microsoft Store. If the Store is temporarily unavailable, scanning and Undo remain available. Before the Store release and Pro offer are configured, purchasing is unavailable.

Which Windows computers does the app target?

The initial release targets 64-bit Intel or AMD PCs running Windows 10 version 2004 (build 19041) or later, including Windows 11. Native ARM64 release verification is pending. Consult the Microsoft Store listing's system requirements when the release becomes available.

Share a problem safely

  1. Describe what you were trying to do and the steps that led to the problem. Use made-up sample filenames when useful.
  2. Include the SyncReady version, Windows version, and the displayed error code. Do not include account credentials or payment details.
  3. If a diagnostic report is needed, open Help in the app and leave Include file and folder paths in this report unchecked before choosing Export diagnostics. Open and review the saved report before sharing it.

GitHub issues are public. Do not attach private filenames, folder paths, documents, recovery records, authentication keys, or unreviewed logs. You need a GitHub account to open an issue. You do not need one to use SyncReady's local features.
